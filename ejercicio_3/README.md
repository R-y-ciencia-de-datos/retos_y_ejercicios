# EJERCICIO #3: Ordenando el caos

## Introducción:

<p align="justify">
La organización de un proyecto es clave para su mantenimiento y escalabilidad. Una estructura clara de carpetas y archivos facilita la colaboración, evita confusiones y reduce el tiempo perdido buscando recursos. En cualquier desarrollo, conviven múltiples tipos de ficheros, mantener todo ordenado es una práctica esencial que distingue un trabajo amateur de uno profesional.
</p>

## Reto:

El junior ha creado un dashboard en Quarto, pero todos los archivos —HTML, css, excel, csv, imágenes y scripts— están mezclados en una sola carpeta. El programador senior, al ver este desorden, propone una solución práctica: escribir un script que organice automáticamente los archivos según su extensión.

El reto consiste en:

- Recorrer los archivos de una carpeta principal.
- Detectar la extensión de cada archivo.
- Crear subcarpetas específicas (ejemplo: html/, css/, js/, img/) en el caso de que no exista.
- Mover cada archivo a su carpeta correspondiente.


## Consideraciones:

-   Preferiblemente utilice las funciones base del lenguaje (**SQL**, **Python**, **R**, **Julia**, **etc**.), evitando librerías externas cuando sea posible.
-   Al nombra el archivo en el que se encuentra su solución deberá seguir la siguiente estructura: *ejercicio_3_[usuario_github].[ext]*
